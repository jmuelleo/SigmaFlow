# Thesis Draft Proposal

Proposed LaTeX draft of **SigmaFlow: Riemannian Flow Matching for Generative
Protein–Ligand Docking** (MSc Statistical Science, 12,000-word limit).

This is a **proposal**, not a declaration. It is deliberately separate from
`Texte/` so that `theory.tex` and its PDF are untouched.

## Build

```
cd Thesis_Draft_Proposal
latexmk -pdf main.tex
```

Requires `lmodern`, `tikz`, `tcolorbox`, `natbib` — all present in the TinyTeX
install used here. No package outside a standard TeX Live distribution.

## Draft annotations

Everything draft-only is generated by three macros defined in `preamble.tex`:

| Macro | Purpose |
|---|---|
| `\begin{reserved}{title}` | A results slot that does not yet exist. States the experiment, expected output, metrics, question answered, and how interpretation depends on the outcome. |
| `\dnote{TAG}{text}` | Short inline annotation, e.g. `RESULT PENDING`, `CHECK WITH SUPERVISOR`. |
| `\figplaceholder{label}{caption}{spec}` | Framed box with a polished caption and a full specification of the final figure. |
| `\tbd` | A single value to be filled in, used inside tables. |

**To produce a clean build with no annotations**, change one line in
`preamble.tex`:

```latex
\draftmodetrue   ->   \draftmodefalse
```

`reserved` blocks then typeset into a discarded box and vanish; `\dnote`
expands to nothing; figure placeholders become plain frames. No source edits
are needed anywhere else.

## Structure

```
main.tex              document, toggles, abstract
preamble.tex          packages, notation macros, draft system
refs.bib              bibliography (every entry verified; gaps flagged, none invented)
chapters/01..09       main text
chapters/A_appendix   appendix skeletons
figures/              (empty; figures are placeholders in the source)
```

## Word count

`scratchpad/wc.py` (session-local) counts prose while excluding displayed
maths, tables, and every draft-only annotation. Current state: **8,021 prose
words**, plus ~1,000 words of planning text inside reserved blocks that do not
count towards the limit.
