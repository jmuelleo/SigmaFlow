SigmaFlow

Interactive supplements to the thesis Riemannian flow matching for generative molecular docking. Everything below is generated from the same evaluation pipeline as the figures and tables in the text.

Pose Mode Explorer Forty generated candidates per complex, clustered into binding modes. Ten complexes, seven from the PoseBusters benchmark set and three from the Astex Diverse Set, for all three models. Both the clustering threshold and the success criterion can be changed, and each mode can be isolated in the 3D view. Sampling trajectories The integration path of a single sample, from the source draw to the returned pose.
Source: github.com/jmuelleo/SigmaFlow. Poses are model output, not experimental structures; the crystallographic pose is drawn in blue for reference.
